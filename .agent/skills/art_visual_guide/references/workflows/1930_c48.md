# Workflow: 1930

## 1. Context and Objective
This workflow guides the analysis of 1930s figurative painting revivals, specifically focusing on American Regionalism and European Realism following World War I.

## 2. Heuristics & Analysis Steps
1. **Evaluate Regional Impacts**: Contrast American regionalists (e.g., Grant Wood) with European Realist renewals (e.g., Fausto Pirandello).
2. **Assess Atmospheric Techniques**: Analyze the use of atmosphere to convey mood, using Edward Hopper's mid-century works (like *Nighthawks*) as a benchmark.
3. **Track Recognition Timelines**: Consider the delay between active creation and public recognition, as seen with Laurence Lowry.
4. **Identify Socio-Political Drivers**: Correlate the return to figurative realism with post-war societal shifts and local cultural identities.

## 3. Output Generation
Produce a comparative analysis detailing how figurative art adapted to localized post-war climates across different regions.
