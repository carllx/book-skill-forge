# The Visual Display of Quantitative Information (量化信息视觉展示)

本技能提炼自 Edward R. Tufte 的《The Visual Display of Quantitative Information》，旨在指导如何高效、准确、优雅地展示量化数据。

## 触发条件

- 当用户需要将大量复杂数据转化为视觉图表时。
- 当用户要求审查、重构或优化现有数据图表设计时。
- 当用户需要避免数据误导，提高图表的“数据墨水比”（Data-Ink Ratio）时。

## 核心心法 (Mindsets)

1. **内容至上 (Substance over Style)**：图表的核心目的是展示数据，应当引导观众思考数据背后的实质含义，而不是被图表的设计方法、技术或装饰所吸引。
2. **多维集成 (Multivariate Integration)**：优秀的图表通常是多维度的，能够在一个平面内展示时间、空间等多个变量的关系（例如 Minard 的拿破仑东征图）。
3. **渐进式披露 (Macro/Micro Readings)**：图表应当在不同的细节层次上展示数据，既能提供宏观的全景概览，也能经得起微观的精细审查。

## 核心原则 (Principles)

1. **图形卓越性 (Graphical Excellence)**：
   - 清晰、精确、高效地传达复杂的定量思想。
   - 在最小的空间内呈现最多的数据。
   - 使庞大的数据集变得连贯、易于比较。
2. **图形完整性 (Graphical Integrity)**：
   - 绝不扭曲数据所传达的信息。
   - 图形中表示效果的物理面积应当与数据中的实际效果成正比（控制 Lie Factor 谎言因子）。
3. **数据-墨水最大化 (Data-Ink Maximization)**：
   - 最大化数据墨水比，即图表中用于表示不可抹除的核心数据的墨水，占整个图形墨水的比例。
   - 擦除多余的非数据墨水。
   - 擦除冗余的数据墨水。
4. **小多图 (Small Multiples)**：
   - 使用相同的图形设计结构，在不同的数据切片中重复展示，便于观众进行纵向或横向的比较，而无需重新学习图表结构。

## 反模式 (Anti-Patterns / 避免的陷阱)

1. **Chartjunk (图表垃圾)**：
   - **Vibrations (视觉震颤)**：过度使用刺眼的波纹、交叉阴影等产生光学错觉的图案。
   - **Grids (喧宾夺主的网格)**：粗重、深色的网格线掩盖了真正的数据。
   - **Ducks (鸭子)**：为了装饰而装饰，过度设计、本末倒置的自我卖弄式图表。
2. **缺乏上下文 (Missing Context)**：孤立的图表，不与文字和统计描述紧密结合，缺乏比较基准。
3. **信息密度过低 (Low Data Density)**：占用很大篇幅却只展示了极少量的数字（例如简单的饼图或只包含几个柱子的柱状图，这些通常用表格更好）。

## 执行 Checklist (Execution Checklist)

- [ ] 图表是否在说真话？是否避免了视觉扭曲（Lie Factor 是否接近 1）？
- [ ] 能否进一步提高“数据-墨水比”？哪些非必要的网格、边框或背景可以去除？
- [ ] 对于时间序列数据，图表是否不仅展示了时间流逝，还引入了其他维度以解释因果关系？
- [ ] 如果有多个相关数据切片，是否考虑了使用“小多图 (Small Multiples)”？
- [ ] 图表是否与正文文字、统计摘要无缝融合？
- [ ] 是否消除了任何试图喧宾夺主的装饰性“图表垃圾 (Chartjunk)”？
