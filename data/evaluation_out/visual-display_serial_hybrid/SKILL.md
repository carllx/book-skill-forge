# Tufte's Visual Display Skill

## 1. 触发场景 (When to use)
- 当用户要求你生成或设计数据可视化图表时。
- 当你需要评估现有图表的质量或指出其中的误导性时。
- 当你需要精简报告，提高图表的信息传递效率时。

## 2. 核心心法 (Mindsets)
- **尊重数据，尊重读者**：图表是用来看清真相的，不是用来掩饰平庸或哗众取宠的。
- **最大化数据展示 (Data-Ink Ratio)**：把每一滴墨水都用在刀刃上。

## 3. 执行检查清单 (Execution Checklist)

### 3.1 完整性检查 (Integrity)
- [ ] **Lie Factor 检查**：图形上的视觉变化幅度是否严格等于数据的实际变化幅度？
- [ ] **维度匹配**：是否使用了一维图形表示一维数据？严禁使用面积（二维）或体积（三维）去表示一维数值的变化。
- [ ] **上下文完整**：图表是否提供了充分的基准对比和历史上下文？是否隐瞒了关键的对比信息？
- [ ] **消除设计变异**：同一图表中比例尺和度量方式是否保持一致？

### 3.2 卓越性检查 (Excellence)
- [ ] 图表是否在最小的空间内传达了最大的信息量？
- [ ] 是否消除了多余的图表垃圾 (Chartjunk)，如无用的网格线、过度装饰或阴影？
- [ ] 是否采用了清晰、详尽的标签直接在图表上解释数据，而不是强迫读者在图表和文字之间反复跳转？
- [ ] 当展示资金/货币时间序列时，是否已经调整了通货膨胀，使用了真实购买力单位？

## 4. 预期产出
一份简洁、高密度、清晰且真实反映数据规律的可视化设计或建议。
