# Architecture: Form, Space, & Order

## 1. 触发条件 (When to use this skill)
当面临以下任务时，请激活此技能：
- 需要进行建筑、室内空间或三维形态的生成与排布设计。
- 试图理解、分析或评价一个现有的建筑空间序列和形式组合。
- 在任何设计过程中遇到“如何将散落的功能元素和几何实体整合为一个连贯整体”的组织学问题。

## 2. 心法原则 (Mindsets & Principles)
基于《建筑：形式、空间和秩序》的宏观思想精华，在一切行动中遵循以下准则：

### 核心心法
- **图底共生 (Figure-Ground Symbiosis)**：空间不是被动的虚无，而是与形式（实体）同等重要的积极要素。建筑设计是图（形式）与底（空间）的双向塑造。
- **原型衍生 (Archetypal Transformation)**：一切复杂的建筑与空间形态，其底层逻辑皆可拆解并溯源至最基础的几何原点：点、线、面、体。
- **动态时空观 (Kinetic Experience)**：建筑不仅仅是静态的雕塑，它必须在时间的推移和人的运动（流线）中被体验，流线是展开空间叙事的轴线。

### 组织与尺度原则
- **秩序法则 (Ordering Principles)**：通过轴线(Axis)、对称(Symmetry)、层级(Hierarchy)、基准(Datum)、韵律(Rhythm)和变换(Transformation)等语法，将杂乱的元素统合为一个连贯的整体。
- **尺度与比例协和 (Proportion and Scale Harmony)**：形式的推敲必须回归到人体的度量尺度，并通过数学或几何的比例系统（如黄金分割、模度）在各部分之间建立内在的视觉和谐。
- **空间组织拓扑 (Spatial Organization Topology)**：依据内在逻辑选择空间阵列模式（集中式、线式、放射式、组团式、网格），而非盲目堆砌。

## 3. 避坑指南 (Anti-Patterns)
- **图底失调 / 孤岛化建筑 (Figure-Ground Disassociation)**：将建筑视作随意摆放在场地上的孤立物体，忽视了建筑对外部负空间（如庭院、街道）的界定与包裹，导致内外割裂。
- **层级迷失 (Loss of Hierarchy)**：在复杂的空间组合中未能通过尺寸、形状或位置的区别来凸显核心空间，导致整体均质化、平庸化，失去焦点和视觉意义。
- **基准缺失 (Datumless Fragmentation)**：在处理多样性和复杂性时，缺乏一根明确的线、面或体积作为参照“基准 (Datum)”，导致各元素散落无序，无法收拢为整体。

## 4. 执行 Checklist (Execution Checklist)
在具体的推演或评价中，请循序渐进地执行以下步骤：

### Phase 1: 形式元素的梳理与几何原型
- [ ] **锚定原型**：识别出核心组件的几何原型（点、线、面、体）以及基础形状（圆、三角、方，或球、圆柱、圆锥、金字塔、立方体）。
- [ ] **形式变换推演**：该形式是通过尺寸变换 (Dimensional)、减法 (Subtractive) 还是加法 (Additive) 演变而来的？
- [ ] **表面与边缘界定**：检查形式的表面特征（颜色、纹理）、边缘转角是否清晰界定并强化了体积感与视觉惯性 (Visual Inertia)。

### Phase 2: 空间与实体的图底咬合
- [ ] **负空间界定**：实体元素（如抬高的基面、下沉的基面、顶棚平面以及垂直墙面，如 L型、U型、平行平面）是否有效地界定了周边的负空间？
- [ ] **图底共生检验**：建筑实体（图）和所围合的虚空（底）是否在图纸（平面/剖面）上具有同等的积极形态和相互塑造的张力？
- [ ] **空间关联拓扑**：分析空间之间的关系模式，它们是“空间中的空间 (Space within a Space)”、“穿插空间 (Interlocking Spaces)”、“相邻空间 (Adjacent Spaces)”还是“由公共空间连接的空间 (Spaces linked by a Common Space)”？
- [ ] **开口的设置**：空间界定面上的开口（面内、转角、面之间）是否合理满足了视线 (View)、采光 (Light) 与空间连贯性的需求？

### Phase 3: 整体秩序与流线的统合
- [ ] **选取空间组织模式**：确认整体布局采用的是集中式 (Centralized)、线式 (Linear)、放射式 (Radial)、组团式 (Clustered) 还是网格 (Grid) 结构？
- [ ] **引入秩序法则**：
    - 是否有一条明确的轴线 (Axis) 或基准面 (Datum) 将各元素系于一体？
    - 哪些空间通过尺寸、形状或独特定位展现了其层级 (Hierarchy) 地位？
- [ ] **动线与时空体验**：路径是如何展开的？从接近 (Approach)、入口 (Entrance)、路径形态 (Path configuration) 到路径-空间关系 (Path-space relationships)，人的动态体验是否具有强烈的节奏感和方向感？
- [ ] **比例验证**：各个独立体块、空间以及开窗之间，是否与人体尺度产生了宜人的比例关系？
