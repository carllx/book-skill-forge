# 触发条件 (Trigger Conditions)
- 当用户要求分析、设计或评估数字媒体（New Media）作品、交互界面或虚拟空间时。
- 当任务涉及探讨“文化界面 (Cultural Interfaces)”、“数据库逻辑 (Database Logic)”、“导航空间 (Navigable Space)”或“合成现实 (Synthetic Realism)”的设计和优化时。
- 当用户需要将传统媒体（如电影、文字）转化为数字媒体格式（Transcoding、Digital Cinema），或进行媒体元素的“合成 (Compositing)”和“空间蒙太奇 (Spatial Montage)”时。

# 心法原则 (Core Principles / Mental Models)
基于图谱提取的核心心法：
1. **数值表示 (Numerical Representation)**: 所有新媒体对象本质上都是由数字代码构成的。它们是可编程的，并受到算法的影响。
2. **模块化 (Modularity)**: 新媒体具有分形的结构，各个媒体元素被组装在一起，但依然保持着独立的结构和身份。
3. **自动化 (Automation)**: 数值编码和模块化结构使得媒体的创建、操作和访问可以被大量自动化。
4. **可变性 (Variability)**: 新媒体对象不是固定不变的，它可以演变并以不同的、甚至潜在无限的版本存在。
5. **跨码性 (Transcoding)**: 媒体转化为其他格式的过程，通常反映了计算机逻辑对文化逻辑的深远影响。

此外，必须认识到新媒体的两大主要**形式 (Form)**：
- **数据库逻辑 (Database Logic)**: 将文化对象结构化为独立条目的集合，而非连续的叙事序列。
- **导航空间 (Navigable Space)**: 将数据或虚拟世界组织为用户可以主动探索的建筑化空间。

# 执行 Checklist (Execution Checklist)
在执行新媒体相关的设计、开发或评估任务时，请逐一检查：
- [ ] **代码化评估**: 该对象是否实现了充分的数值表示？能否通过算法对其进行有效操作？
- [ ] **模块化设计**: 媒体元素是否是独立可复用的？修改某个元素是否会破坏整体结构？
- [ ] **自动化潜力挖掘**: 在创建流程或用户访问环节，是否利用了计算能力实现自动化？
- [ ] **多版本与可变性支持**: 系统是否支持生成定制化、多版本的媒体输出？
- [ ] **文化界面 (Cultural Interfaces)**: 界面设计是否合理融合了印刷物、电影和人机交互（HCI）的传统？
- [ ] **数据库与叙事重构**: 内容组织是否充分运用了“数据库逻辑”而非单一线性叙事？
- [ ] **空间导航 (Navigable Space)**: 环境或数据结构是否提供了直观、可探索的空间隐喻？
- [ ] **合成与蒙太奇 (Compositing & Spatial Montage)**: 在视觉呈现上，是否实现了元素的无缝合成，或在同一屏幕上使用“空间蒙太奇”展示多重信息？
- [ ] **合成现实与远程动作 (Synthetic Realism & Teleaction)**: 是否正确运用了计算机生成的错觉（Illusion），并支持实时的远程行动？
