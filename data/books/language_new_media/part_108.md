Metalanguage is the language used for the analysis of object language. Thus, a metalanguage may be thought of as a language about another language. A   
metatext is a text in metalanguage about a text in object language. For instance, an article in a fashion magazine is a metatext about the text of cloves. Or, HTML file is a metatext which desribes the text of a Web page.
