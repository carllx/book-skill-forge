# BSF (Book-Skill-Forge) 全局项目上下文

## 1. 核心愿景 (North Star)
BSF 不是一个一次性的代码库，而是一个**持续运营、持续学习、持续研究、持续迭代**的“书籍转技能”测试实验室 (Test-Bench)。
随着 V6 Native IDE 架构的全面升级，系统现已全面依托 Antigravity IDE 的原生扩展机制。我们的目标是通过 `.agent/` 扩展能力，实现极低摩擦、高并发、深层融合的知识提取实验平台。

## 2. 核心架构与沙盒引擎
V6 架构全面拥抱 Antigravity IDE，抛弃了复杂的 Python/LLM 中间件，改为纯粹的配置化和原生隔离机制。
关于详细的 `.agent/` 目录规范、沙盒隔离原理以及 Knowledge Items (KIs) 的定义，请[详见 V6 核心目录规范](ARCHITECTURE.md#2-核心目录规范-v6-native)。

## 3. 脱水评测与审计纪律
我们坚持多维度、多管线的横向评测体系，以寻找提取质量的最优解。
关于评测执行流程、脱水计分公式、双向证据映射与语义容错红线，请[详见评测标准与 SOP 手册](EVALUATION_GUIDELINE.md)。

## 4. 架构红线与设计原则 (不可违背)
- **绝对的数据驱动与规则约束**：必须遵守 `.agent/rules/` 设定的约束。
- **脱水评测信仰**：一切评测遵循 SSOT 计分红线，禁止主观打分。
- **职责解耦**：工作流只负责声明式流转，Skill 只负责专注提纯，环境隔离由 Rule 兜底。
